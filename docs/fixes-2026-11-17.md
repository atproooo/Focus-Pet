# Calendar and timer fixes — 2026-11-17

Daily credited progress now resets on local date changes, and the home and statistics screens refresh at midnight or on return to the foreground. Calendar statistics are rebuilt from claimed session completion dates, allowing consecutive days, missed days and delayed claims to be handled consistently. Legacy calendar statistics are initialized from existing claimed history without reissuing rewards or changing cumulative progress.

Sessions ended before one minute are saved as cancelled. Cancellation updates only running sessions, protecting settled rewards. History labels are shortened at complete grapheme boundaries, preserving emoji and combining characters. Timer ticks and pause/resume commands now share the service looper, preventing rapid resume from leaving the timer without a worker.

Early-ending progress intentionally remains discounted: ten actual minutes can award three XP and count as three minutes of goal progress. Reset-all behavior is outside this change.

Validation: debug and release builds, eight local unit tests, and 33 emulator regression cases passed on API 37. The device cases included an external UI/service test harness; focused calendar and label regression tests are included in the repository. Tests cover calendar rollover, streaks and gaps, legacy statistics, Unicode labels, short cancellation, settled reward protection, background timing, and repeated rapid pause/resume. Calendar rollover is simulated with a controllable clock and date fixtures; real-device and long-term sleep coverage remains pending.
